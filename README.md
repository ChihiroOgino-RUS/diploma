# Дипломный проект — курс «Автотестирование»

Дипломный проект по курсу автоматизации тестирования. В рамках проекта выполняется автоматизация тестирования веб-сервиса: UI- и API-тесты, проверка основных сценариев работы приложения.

## Цель проекта

- Спроектировать и реализовать автоматизированные тесты для ключевых сценариев работы сервиса.
- Покрыть тестами как пользовательский интерфейс, так и API.
- Настроить формирование отчётов о результатах прогона.

## Планируемый стек

> Уточняется по мере выполнения проекта.

- Java 11
- JUnit
- Selenium WebDriver / Selenide
- RestAssured (для API-тестов)
- Maven / Gradle
- Allure (отчёты о тестировании)
